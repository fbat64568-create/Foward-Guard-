# FORWARD GUARD — Demo Website

A premium, responsive fictional defense-technology/personnel-support website built with:
- HTML5
- CSS3
- Vanilla JavaScript

## Files
- `index.html`
- `style.css`
- `script.js`

## Important
This is deliberately a fictional demonstration platform. It is not affiliated with any government, military, intelligence agency, or defense organization.

The news cards are placeholders. They do NOT claim to be live news. For production use, connect the dashboard to legitimate news APIs/RSS feeds and preserve source attribution and publication timestamps.

The application/contact forms are demonstration-only and do not transmit data.

## Netlify
Upload the ZIP directly to Netlify for a quick deployment, or extract the files into a GitHub repository with `index.html` at the repository root and connect that repository to Netlify for automatic future deployments.
